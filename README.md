# Zomato Bangalore Restaurants — Data Cleaning & Preprocessing

## Project Overview

This project focuses on cleaning and preprocessing a real-world Zomato Bangalore restaurant dataset using Python and Pandas.

## Cleaning Performed

- Analyzed missing values column by column
- Handled missing values using justified median and mode imputation
- Removed irrelevant columns with excessive/irrelevant data
- Identified duplicate records
- Detected outliers using the IQR method
- Documented decisions on retaining genuine outliers
- Encoded categorical variables into numerical values
- Compared the dataset before and after cleaning

## Dataset

The dataset contains **51,717 restaurant records** and **17 original columns**.

After cleaning, the dataset contains **51,717 rows and 15 columns**, with **0 missing values and 0 duplicate rows**.
